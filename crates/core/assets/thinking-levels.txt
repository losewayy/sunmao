# reasoning-effort level sets per model family — what `thinking` actually
# accepts on the wire, verified against each provider's API docs (2026-10).
# Format: `globs | levels` per line — comma-separated globs share a row;
# the glob matches the NORMALIZED model id (vendor/pool stripped,
# non-alnum folded to '-'); first match wins.
#   levels = comma list of accepted effort levels → `thinking`
#   `-`    = thinking is a plain toggle (or always-on), no level vocab
#            → `reasoning` flag only
#   `!`    = definitively NO thinking — actively suppresses guesses
#            (e.g. kimi-k2 instruct inside a thinking family)
# Rows not listed inherit the refresh-time fallback (a supported
# reasoning_effort param earns the OAI-baseline low/medium/high guess).

# — OpenAI (reasoning_effort / reasoning.effort) —
# gpt-6-astra rejects `none` (400); 6.1-sol rejects none+minimal; other
# gpt-6 (sol/luna/terra) accept none; gpt-5.6 adds minimal+max on the
# full ladder; gpt-5.1's codex-max is the first xhigh carrier. Image
# and audio models, gpt-4.5, and the safeguard guardrail take no effort.
gpt-*-image*,gpt-audio*,gpt-4-5-preview,gpt-oss-safeguard* | !
gpt-6-astra* | low,medium,high,xhigh,max
gpt-6-1* | low,medium,high
gpt-6* | none,low,medium,high,xhigh
gpt-5-6* | none,minimal,low,medium,high,xhigh,max
gpt-5-5* | none,low,medium,high,xhigh
gpt-5-1-codex-max* | none,low,medium,high,xhigh
gpt-5-1* | none,low,medium,high
gpt-5-pro* | high
gpt-5-2*,gpt-5-3*,gpt-5-4* | none,low,medium,high,xhigh
gpt-5* | low,medium,high
gpt-oss-* | low,medium,high
o1*,o3*,o4-* | low,medium,high
