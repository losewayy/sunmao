01pipeline

User prompt → tool call, end to end

One turn is a straight circuit with two side rails: the hook dispatcher (advises, can veto or rewrite) and the session log (records, is the replay source of truth). Everything below is the same path whether the prompt arrived from stdin, the TUI, or an ACP peer.

1

Enter the loop

core/agent/turn.rs · core/agent/mod.rs entry

AgentLoop::run_turn(prompt, observer). The call serializes through ctx.turn_lock — one turn per Context, so two concurrent turns can never interleave facts into one log. compact, swap_session and record_local_shell fence on the same lock.

2

UserPromptSubmit hooks

core/hooks.rs hook

Command handlers + extension children fire on one path. An outcome can rewrite the prompt, inject context, or veto the turn. Every rewrite is recorded as a Hook fact — transparent to the model, durable for the auditor.

3

Context assembly — fold the log

core/session.rs · core/prompt.rs · assets/prompt/*.md state

ctx.sessions.messages() reduces SessionEvent[] → Message[]. File-backed and ephemeral logs run the identical fold — replay is the test. PromptAssembler layers built-in assets → user → project → project context; a same-named file replaces an earlier section (the cold-plug rule). TodoWrite state is injected at head-of-request so compaction can't lose the plan.

4

Stream from the provider

llm/oai.rs · llm/anthropic.rs · llm/sse.rs · llm/assemble.rs wire

ctx.active_llm().stream(ChatRequest) → raw SSE bytes → SseParser → StreamDelta (content / reasoning / tool-call fragment). Retry only on request-establishment failures (connect · 429 · 5xx, backoff 300/600ms); once deltas flow there is no replay.

5

Reassemble tool calls

llm/assemble.rs wire

assembler.push() accumulates fragmented arguments (Anthropic input_json_delta, OAI tool_calls deltas); finish_lenient() returns the call plus an error map for malformed JSON. Bad calls become failed ToolResults so the model self-corrects instead of the turn aborting.

6

Per tool_call — the dispatch gate

core/agent/gate.rs gate
  • ctx.permissions.check() — ordered verdict deny > ask > allow > default; a deny is a hard refusal, not a prompt.
  • Bash only: shell_segments() in core/preflight.rs splits &&/;/|| into independently-judged segments. Pipelines stay whole — the split is the structural gate, and the | sh family needs the joined text.
  • ctx.approval.approve() — risky calls park for a verdict (REPL stdin · TUI card · ACP request_permission). A session grant covers the identical call, nothing broader.
  • hooks.fire(PreToolUse) — an exit-2 veto aborts the call before it runs.
7

Execute + persist the pair

core/tool/* · registry.call(name, args, ctx) state

The shared registry dispatches — built-ins, boxed MCP tools, ext__* tools and Task all live in one table. The call lands as SessionEvent::ToolCall + ToolResult (the audit trail), then hooks.fire(PostToolUse) — and PostToolUseFailure when the result failed. Live deltas also reach the Observer sink as LiveEvents, which never persist.

8

Durable before the next turn

core/session.rs close

The assistant Message is persisted before the next request leaves — a crash mid-turn leaves a stranded tool_call, and the fold repairs it with a synthetic [interrupted] result (providers reject unpaired tool_use). The cancelled flag is consumed at turn end: a cancel issued before run_turn still takes effect; the next turn starts clean.

↓ append-only JSONL · repair-on-fold · replay ≡ live. The visible transcript is a pure fold over the events.

03tui internals

The four mechanisms that keep a long transcript cheap and readable

Completion popups · fold-by-cap · virtualization · paste placeholders

cli/tui/{menu,replay,render,app}.rs

menu kinds

MenuKind decides the title, the hint and the accept action.

  • Command — /… builtin + convention-dir commands
  • Args — the argument of a chosen builtin (today /model selectors)
  • Sessions — /resume / /sessions picker, newest first, 50 cap
  • Path — @… repo-relative mention; accepts in place, dirs keep / and reopen

@ preempts the slash menu; both are dead in bash mode. Rows render in an 8-row window with a ▼ n of m indicator.

fold-by-cap

On close_turn(), a turn keeps its last TURN_CAP = 12 steps; older ones collapse into a StepSummary block where the first folded step sat.

  • Steps = Assistant · Thinking · Tool
  • Audit/note rows are spine, never folded
  • Summary reads “N tool calls · M thinking · K messages folded”
  • e splices the folded steps back
  • Selection is remapped so scrollback keeps pointing at the same content

virtualization

draw_transcript runs two passes over the block list:

  • Pass 1 — per-block wrap cache keyed by (gen, width, selected); a streaming token re-wraps only its own block
  • Pass 2 — heights for all blocks, lines only for the viewport window

Clone cost scales with what's visible, not with transcript size. render_cache.clear() on a fold. Scrollback keeps the selected block in view.

paste placeholders

Bracketed paste ≥ PASTE_STASH_LIMIT = 2048 bytes stashes the content and inserts a [paste #N] marker — one splice, one menu refresh, no per-char O(n²).

  • expand_pastes() inlines the bytes at submit, wrapped in <pasted-text>
  • Template dispatch expands markers too, so $ARGUMENTS still flows
  • History stores the compact marker, not the payload
  • ! local bash keeps the marker literal — it isn't the model's convention

Event → block fold

cli/tui/replay.rs · blocks.rs

same sinks, two origins

Live wire events and a --resume replay drive the identical stream / tool_start / tool_done / push_audit sinks — a resumed session renders what a live one produced, all closed.

verb-grouping

A repeated tool at the same depth+lane re-arms the finished row: one Read ×3 instead of three. Lanes keep parallel batch children distinct.

lane & depth

depth > 0 marks sub-agent calls; lane is unique across the whole spawn tree, so a frontend can prove distinctness without racing live events.

audit lines stay

⚙ rows for Hook facts, TaskDone and hook-injected context are always visible and never fold into a tool block.

04seams

The seams are ctx.* — one struct, every contract

Context (core/context.rs) is the seam assembly struct: the loop, the tools and every frontend read the same fields. A trait only appears once a second real implementation needs it — concrete until then.

ctx.llm · ctx.llm_override

Arc<dyn ProviderAdapter> · RwLock<Option<…>>

Two live dialects (OAI, Anthropic) earn the trait. The override is the mid-session /model seam; the loop reads through active_llm().

ctx.sessions

Arc<tokio::sync::Mutex<SessionLog>>

Event log + fold. Arc because detached Task children outlive their spawn call and append TaskDone straight into the parent's log.

ctx.tools

ToolRegistry (concrete map)

Built-ins + boxed MCP tools + ext__* tools + Task share one dispatch table — one surface, one place to trim.

ctx.hooks

HookEngine — one dispatcher

Any number of command handlers plus extension children; dialect-compatible with the Claude contract. An exit-2 PreToolUse is a veto.

ctx.approval

Arc<dyn Approver>

Three frontends, one trait: REPL stdin, TUI y/n card, ACP session/request_permission.

ctx.permissions · ctx.risk_table

Permissions · Vec<(pattern, reason)>

Rules from JSON, judgement from a text asset. Replace the file and the gate's judgement changes — no code edit.

ctx.ext

Arc<ExtRegistry>

One spawned child per extension spec; its tools register into ctx.tools and its events ride ctx.hooks.

ctx.live_sink

OnceLock<Arc<dyn Observer>>

The live-event sink: REPL writer / TUI channel / ACP notifications. None = discard, the historical -p-and-tests behaviour. Nothing here persists.

ctx.read_paths · ctx.session_grants

Mutex<HashSet<PathBuf>> · Arc<Mutex<HashSet<String>>>

The read-before-write ledger and the session's exact-match approval grants. Grants are Arc so sub-agents share the interactive session's.

ctx.cancelled · ctx.turn_lock

AtomicBool · tokio::sync::Mutex<()>

Cooperative cancel (consumed at turn end, not start) and the one-turn-per-Context fence that keeps replay honest.

ctx.depth · ctx.lane

u8 · u8 (+ shared AtomicU8 counter)

Nesting depth for the Task depth cap, and a lane unique across the whole spawn tree so parallel children's tool events stay attributable.

ctx.models · ctx.agent_name · ctx.loop_driver

Option<Arc<ModelResolver>> · Option<String> · LoopDriver

Routing (.sunmao/models.json, @routes), the agent def that gates spawns:, and the replaceable loop — Bare skips hooks, the gate and compaction but keeps the log and observer.

ctx.live_tasks · ctx.todos

Arc<Mutex<Vec<TaskEntry>>> · Mutex<Vec<TodoItem>>

The sub-agent roster (/tasks) and the hot snapshot of the model's task list — the LOG stays the source of truth; this is what readers hit.

ctx.extra_plugin_roots

Vec<PathBuf>

Resolved --preset dirs. Install via with_extra_plugin_roots so hooks, permissions, the risk table and the loop driver all reload.

ctx.session_id · ctx.cwd

String · PathBuf

The log's file stem and the tool path base. Hook payloads (session_id, transcript_path) point at a file that exists, not a placeholder.

from ARCHITECTURE.md — where contracts live

05shape rules

Enforced, not aspirational

cargo run -p xtask -- arch fails CI on god files, layer inversions and prose-in-code. Its two exemptions are encoded: #[cfg(test)] and Tool::function(...) call sites.

No god filesA file past ~600 lines splits by responsibility — tests count toward the budget. Navigability, not hiding bulk.
Layers run one waycli → core → llm, never backwards. llm doesn't know sessions exist; core doesn't know the TUI exists.
Cold-plug, not hot-plugPrompts and policy tables are data files (include_str! shipped, user files replace by name). A hardcoded prompt is a seam violation even though it compiles.
Seams earn existenceA trait appears only when a second real implementation needs it. Concrete types until then; a wrong commit gets a follow-up, never a rewrite of main.
source of truth: docs/ARCHITECTURE.md (state) · docs/CODE-ARCHITECTURE.md (shape) · AGENTS.md (invariants). When they disagree, ARCHITECTURE.md wins — update SPEC or fix the code.
