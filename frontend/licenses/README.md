# License sources

Runtime dependency licenses normally come directly from their installed npm packages. `react-remove-scroll-bar` 2.3.8 omits its LICENSE from the tarball; its complete license is copied verbatim from [the official repository at commit 8ca9ba5](https://github.com/theKashey/react-remove-scroll-bar/blob/8ca9ba5ea52de03308fe8ced94f7b159a44d28ff/LICENSE). The build fails if a dependency has no packaged license or explicit local copy.
